# SwiftApp demo

[Watch the rider and driver demo](https://github.com/freaknu/swift_app/issues/1) · [Download MP4](swift-app-demo.mp4) · [Live API docs](https://swift-app.duckdns.org/swagger-ui.html)

[![SwiftApp rider and driver demo](swift-app-demo-poster.png)](https://github.com/freaknu/swift_app/issues/1)

A 70-second walkthrough of the real Flutter UI: rider route and vehicle selection, driver availability and offers, active trip controls, rider tracking and a sample payment receipt. The video is 1920×1080 H.264/AAC at 30 FPS with an original ambient score.

The persistent demo-data label identifies an isolated, simulated journey. Map content and payment responses are illustrative. No real ride, GPS update, chat message or payment was submitted during capture. Razorpay integration uses test mode. The ordinary app entry point was restored after recording.

The hosted backend was checked independently through its HTTPS API and authenticated STOMP/WebSocket endpoint, including the app's actual Flutter clients on an Android emulator. This walkthrough is a UI demonstration and does not certify live payments, production load or a fixed device frame rate.
